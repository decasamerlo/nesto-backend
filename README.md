# Nesto Backend

Java + Spring Boot API server for the Nesto task/list management app.

## What This Does

REST API backend powering Nesto. Built with Hexagonal Architecture (ports & adapters) and a self-referential `Node` domain model that represents a recursive tree of tasks and lists. All domain logic is unit-testable with zero Spring context or DB.

## Tech Stack

- **Language**: Java
- **Framework**: Spring Boot
- **Architecture**: Hexagonal Architecture (ports & adapters)
- **Database**: Postgres
- **Migration**: Flyway
